# Обзор зависимостей математического ядра

Runtime-зависимость baseline — **NumPy 2.x**, тестовая — **pytest 8.x**.

NumPy используется только для:

- хранения `P`, `P*`, `T_ij` и векторов;
- нормализации;
- числовых проверок;
- сериализуемого преобразования матриц.

Построчное вычисление новых весов намеренно реализовано явным двойным циклом,
чтобы код буквально повторял ручную запись:

```text
row element × previous vector element → сумма строки
```

Majority, отбор двух быстрых наблюдений, триады, `P*`, статусы и trace также
реализованы явно. Это предметная формула проекта, а не задача ML.

SciPy, scikit-learn, pandas и Pydantic baseline не требуются. Bradley–Terry,
Thurstone, AHP, Rank Centrality и байесовские модели могут исследоваться только
как отдельные версионированные альтернативы после утверждения baseline.
