# Соответствие техническому заданию

Статус фиксируется только при наличии воспроизводимой проверки. Документ относится
к готовому Desktop-прототипу 1.0.0; Web оставлен на следующий этап по решению заказчика.

- [ ] Две самостоятельные реализации — Desktop готов, Web ещё не реализован.
- [x] Фиксация данных эксперимента — `comparison_responses`, тест полного сценария.
- [x] Три режима времени — `timeout_skip`, `timeout_mark`, `no_limit`.
- [x] Минимум две категории — валидация редактора и тесты width=2.
- [x] Нечётная глубина активной коллекции не меньше 5 — валидация и API-тест.
- [x] Тренировочный режим — три отдельных предъявления, исключённых из аналитики.
- [x] Фиксация времени реакции — `performance.now()` после загрузки обеих картинок.
- [ ] PostgreSQL — ORM совместима, но интеграционное испытание PostgreSQL ещё не выполнено.
- [x] Node.js, React и TypeScript — production-сборка Vite/Electron выполнена.
- [x] Windows 10+ — установщик собран на Windows 10 (10.0.19045).
- [x] Автоматическое сохранение — отдельная SQLite-транзакция после каждого ответа.
- [x] Первичная математическая обработка — 29 тестов научного ядра.
- [x] Итоговые отчёты — PDF, пользовательский XLSX и массовый ADMIN XLSX проверены тестом.
- [x] Модульная архитектура — analytics, persistence, application-service, reports, UI, Electron.
- [ ] Метрологическая гарантия 1 мс — есть диагностика разрешения таймера, но требуется
  отдельное испытание на целевом оборудовании.

## Воспроизводимые основания

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m alembic check
pnpm desktop:typecheck
pnpm desktop:build
```

Текущий результат: 37 тестов, схема Alembic без расхождений, production-сборка и
smoke-запуск упакованного приложения успешны.
