# Соответствие техническому заданию

Статус отмечается только при наличии воспроизводимой проверки. Сейчас в работе
Desktop 2.0; Web отложен по решению заказчика.

- [ ] Две самостоятельные реализации — Desktop реализован, Web отложен.
- [x] Фиксация данных эксперимента — SQLite и тест полного сценария.
- [x] Три режима времени — `timeout_skip`, `timeout_mark`, `no_limit`.
- [x] Минимум две категории — валидация и тест `width=2`.
- [x] Положительная нечётная глубина `1, 3, 5, ...` — сервисная валидация и тест.
- [ ] Тренировочный режим — намеренно отключён в упрощённом Desktop.
- [x] Фиксация времени реакции — `performance.now()` после загрузки изображений.
- [ ] PostgreSQL — исключён из текущего Desktop; потребуется в Web-версии.
- [x] Node.js, React и TypeScript — Electron/Vite production-сборка.
- [x] Windows 10+ — Windows-установщик собирается Electron Builder.
- [x] Автоматическое сохранение — SQLite-транзакция после каждого ответа.
- [x] Первичная математическая обработка — pytest и контрольный пример XLSX.
- [x] Итоговые отчёты — PDF, пользовательский и массовый XLSX.
- [x] Модульная архитектура — analytics, db, service, worker, Electron, React.
- [ ] Метрологическая гарантия 1 мс — требуется испытание на целевом оборудовании.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
pnpm desktop:typecheck
pnpm desktop:build
```

SQL-схема применяется простыми файлами из `src/db/migrations`; Alembic и ORM в
Desktop 2.0 не используются.
