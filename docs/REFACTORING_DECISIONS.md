# Упрощение Desktop 2.0

Desktop 2.0 удаляет локальный HTTP-контур из исполняемой архитектуры. React вызывает
Electron IPC, Electron передаёт JSON одному постоянному Python worker через
stdin/stdout, а worker вызывает сервисные функции напрямую.

Удалены из нового контура:

- FastAPI, Uvicorn, HTTP endpoints и `fetch`;
- SQLAlchemy, repository pattern и Alembic;
- Pydantic HTTP-модели;
- обязательные тренировочные предъявления.

SQLite обслуживается стандартным `sqlite3`. Два SQL-файла создают недостающие
таблицы с `IF NOT EXISTS`, поэтому существующая база Desktop 1.0 принимается без
пересоздания и потери записей. Старый и новый форматы snapshot читаются одним
адаптером.

## Почему worker всё ещё упаковывается

Electron/Node.js не умеет импортировать Python-модуль напрямую. Передача только
исходников потребовала бы установленного Python на каждом компьютере. Поэтому
PyInstaller оставлен как последний упаковочный шаг, а не как отдельный сервис:
он создаёт один переносимый worker текущей платформы.

Скрипт `scripts/build.py` одинаков на Windows, macOS и Linux. Он собирает worker
на текущей платформе и выбирает соответствующую цель Electron Builder.

Математический пакет `prisma/analytics` не изменялся.
