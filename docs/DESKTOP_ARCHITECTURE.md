# Архитектура Desktop 1.0

Electron отвечает только за окно и жизненный цикл локального сервиса. React не
содержит математических формул. Все ответы сохраняются FastAPI-сервисом в SQLite,
после чего тот же Python-пакет `prisma.analytics` формирует оба режима результата.

Основные границы:

- `prisma/analytics` — заменяемое научное ядро и только его модели;
- `prisma/persistence` — SQLAlchemy-модели и репозитории;
- `apps/service/prisma_service` — аутентификация, сценарии, API, PDF/XLSX;
- `packages/ui` — общий React-интерфейс и клиентский таймер;
- `apps/desktop` — безопасная Electron-оболочка и Windows-упаковка.

Сессия хранит snapshot коллекции, random seed и фактический порядок с левым/правым
положением. Тренировочные ответы помечены отдельно. Каждый основной ответ фиксируется
до показа следующей пары. Изменение или удаление коллекции не меняет историю.

Пароли хешируются `scrypt`. Renderer работает с `contextIsolation`, без Node API и
без прямого доступа к файлам/БД. Пользовательские SVG запрещены; принимаются только
проверенные Pillow растровые изображения до 10 МБ.
