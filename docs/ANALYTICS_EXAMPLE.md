# Проверяемый пример majority → P → P* → веса

Используются типы `A`, `B`, `C` и глубина 3.

## Повторные наблюдения

| Пара | Level | Выбран | Время, ms |
|---|---:|---|---:|
| A–B | 1 | A | 100 |
| A–B | 2 | A | 200 |
| A–B | 3 | B | 50 |
| A–C | 1 | C | 100 |
| A–C | 2 | C | 300 |
| A–C | 3 | A | 50 |
| B–C | 1 | C | 150 |
| B–C | 2 | C | 250 |
| B–C | 3 | B | 40 |

Для каждой пары большая группа содержит два наблюдения, поэтому выбираются оба:

```text
A–B: победитель A, T_AB = 100+200 = 300
A–C: победитель C, T_AC = 100+300 = 400
B–C: победитель C, T_BC = 150+250 = 400

T = 300+400+400 = 1100
```

Быстрые ответы меньшей группы (`50`, `50`, `40`) отбрасываются: сначала
определяется большинство, и только затем время.

## Матрица P и согласованность

Получено `A>B`, `C>A`, `C>B`:

```text
P = [[NaN, 1, 0],
     [0, NaN, 0],
     [1, 1, NaN]]
```

Циклических триад нет:

```text
C = 0
Cmax = 1
zeta = 1
```

```text
P* = [[NaN,     0.727273, 0.363636],

```

## Построчная итерация

Стартовый нормированный вектор:

```text
W(0) = [1/3, 1/3, 1/3]
```

Первая итерация считается по строкам с одним неизменным `W(0)`:

```text
raw_A = 0×1/3 + 0.727273×1/3 + 0.363636×1/3 = 0.363636
raw_B = 0×1/3 + 0×1/3        + 0.363636×1/3 = 0.121212
raw_C = 1×1/3 + 1×1/3        + 0×1/3        = 0.666667

sum(raw) = 1.151515
W(1) = [0.315789, 0.105263, 0.578947]
```

Следующие нормированные векторы:

```text
W(2) = [0.312500, 0.229167, 0.458333]
W(3) = [0.320000, 0.160000, 0.520000]
...
W(8) = [0.315980, 0.182936, 0.501085]
```

На итерации 8 `delta=0.000852<0.001`.

Итог choice+time:

```text
A = 31.5980%
B = 18.2936%
C = 50.1085%
```

Choice-only для этой полностью согласованной `P` использует рабочую стратегию
`self_retention_prototype_v1`: к сумме строки добавляется предыдущее значение
самого типа. Результат сходится за 43 итерации:

```text
A = 4.2512%
B = 0.0966%
C = 95.6522%
```

Буквальная стратегия без добавочного собственного значения сохранена отдельно
как `literal_source_v1`; для этой бинарной матрицы она доходит до нулевой суммы.

## Контрольное расхождение source_v1 / symmetric_candidate_v2

Для тестового турнира четырёх типов и одинаковых времён получены разные нижние
треугольники:

```text
P* source_v1 =
[[NaN, 1/6, 1/6, 1/6],
 [1,   NaN, 1/6, 5/6],
 [1,   1,   NaN, 1/6],
 [1,   0,   1,   NaN]]

P* symmetric_candidate_v2 =
[[NaN, 1/6, 1/6, 1/6],
 [5/6, NaN, 1/6, 5/6],
 [5/6, 5/6, NaN, 1/6],
 [5/6, 1/6, 5/6, NaN]]
```

Итоговые проценты:

| Тип | source_v1 | symmetric candidate | Разница, п.п. |
|---|---:|---:|---:|
| A | 10.555203 | 11.227309 | +0.672106 |

| C | 31.230305 | 29.590897 | −1.639408 |
| D | 29.620783 | 29.590897 | −0.029886 |

`source_v1` остаётся baseline. Симметричный вариант не утверждён и существует
только как явно вызываемый экспериментальный кандидат.
